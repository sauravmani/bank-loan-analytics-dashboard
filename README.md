# Bank Loan Analytics Dashboard

## Project Overview

An interactive Power BI dashboard for analyzing bank loan applications, amount funded, repayments, loan status, interest rates, DTI ratio, and patterns among borrowers.

The dashboard is aimed at providing an analysis of the loan portfolio performance via interactive KPIs, charts and filters.

## Objectives

- Analysis of overall loan application performance
- Funding amount and amount received tracking
- Analysis of Good Loan and Bad Loan applications
- Analysis of loan status and performance in repayments
- Analysis of monthly trends in loan applications
- Loan applications by state analysis
- Loan terms, ownership, and purpose of loan
- Interest rate and DTI ratio analysis

## Tools & Technologies

- Power BI
- Power Query
- DAX
- Microsoft Excel / CSV

## Dashboard Pages

### 1. Summary

The Summary page gives you a general overview of loan portfolio performance, including:

- Total Loan Applications
- Total Funded Amount
- Total Amount Received
- Average Interest Rate
- Average DTI Ratio
- Good Loan vs Bad Loan analysis
- Funded Amount vs Repayment
- Loan Applications by Loan Status
- Average Interest Rate by Loan Status
- Average DTI Ratio by Loan Status

### 2. Overview

The Overview section contains a detailed analysis using:

- Monthly Loan Applications
- Loan Applications by State
- Loan Applications by Loan Term
- Loan Applications by Home Ownership
- Loan Applications by Loan Purpose
